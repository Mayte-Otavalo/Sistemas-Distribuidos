# Distributed Systems - Lab 2

This laboratory focuses on communication and messaging in distributed systems using Python.

## Topics

* **RMI:** Remote matrix operations using Pyro4 and NumPy.
* **Pub/Sub:** Communication between multiple publishers and subscribers using ZeroMQ.
* **Pipeline:** Task distribution between sources, a broker, and workers using ZeroMQ.

## Technologies

* Python
* Pyro4
* NumPy
* ZeroMQ (pyzmq)

## Main Activities

1. Distributed matrix operations.
2. Multi-publisher and multi-subscriber communication.
3. Broker-worker task processing.
